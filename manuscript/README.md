# Technical report

`Ingence_v0.4.0_Technical_Report.pdf` is the technical report "Ingence: An indexing and inference
engine that relates data organization to experimental structure". It describes Ingence 0.4.0.

The report is under the Creative Commons Attribution 4.0 license (CC BY 4.0), not the MIT license
of the code. The text is in [`../LICENSES/CC-BY-4.0.txt`](../LICENSES/CC-BY-4.0.txt).

The report's supplemental material is on Zenodo under CC0: the sample laboratory data collection,
the scoring and figure scripts, and the code used to read the public archives. It is at
https://doi.org/10.5281/zenodo.23756686. That record holds the materials of the report, not the
software.
