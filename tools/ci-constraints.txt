# Versions of the tools whose output is compared with files in this repository.
#
# The committed schemas, the lint and the type check were made with the versions below. A newer
# release of one of these tools can write a different file or find a different fault with no change
# to this repository. To get the same results, install for development with
# `-c tools/ci-constraints.txt`, which holds each of them at the version the committed files were
# made with. A person who only installs Ingence is not affected: the package's own requirements
# (pyproject.toml) are not pinned.
#
# To move to newer versions: install them in a clean environment, run
# `python tools/export_schemas.py`, `ruff format .` and `mypy src/ingence`, commit what changed, and
# change the versions here in the same commit.
